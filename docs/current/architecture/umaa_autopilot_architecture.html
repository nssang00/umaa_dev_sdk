필요한 바이너리만 배포 · DDS Data Bus에 외부 Component 연결
범위와 표준 구분: 본 문서는 기존 논의 내용을 시각화한 제안 아키텍처야. 대표 Service의 일부 Topic/Operation은 축약·설명용 표기이며, 정확한 이름과 의무 구현 범위는 적용 대상 UMAA ICD/IDL 버전으로 확정해야 해. Service 내부 구현, C ABI, 언어 바인딩, 프로토콜 엔진, DDS Adapter 및 DLL/SO 패키징은 UMAA가 강제하는 계층이 아니라 설계 선택이야. 공유 라이브러리로 링크된 의존성은 최종 Component 바이너리에 자동으로 합쳐지지 않아.
